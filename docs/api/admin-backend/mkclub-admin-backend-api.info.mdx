**API multi-tenant do painel administrativo MKClub.**

## Autenticação

- **JWT (Bearer):** Use o token retornado pelo Auth Service (`POST /auth/login`) no header `Authorization: Bearer `token``. Obrigatório para a maioria dos endpoints (usuários logados no admin).
- **Tenant API Key (integrações):** Para acesso por tenant (ex.: sistemas externos), envie `X-API-Key` e `X-API-Secret` nos headers. As chaves são geradas ao criar o tenant (Super Admin) e podem ser regeneradas em `POST /tenants/:id/regenerate-keys`.

## Roles

- **SuperAdmin:** Acesso total; pode criar/listar tenants, ver dashboard global, configurar gateways de qualquer tenant.
- **Admin:** B2B; cria e gerencia seus próprios tenants, isolado de outros Admins.
- **TenantAdmin:** Acesso restrito ao próprio tenant; pode gerenciar campanhas, gateways e conteúdo do seu tenant.
- **User:** Usuário final, escopado por tenant quando aplicável.
- **Star:** Artista/estrela vinculado a campanhas; acesso a splits de receita.

## Recursos principais

| Recurso | Descrição |
|--------|-----------|
| **Tenants** | CRUD de tenants (Super Admin). Cada tenant tem apiKey/secretKey e opcionalmente contratos CW20/NFT na Xion. |
| **Payment Gateways** | Configurar Stripe/Mercado Pago por tenant, testar conexão, checkout, charge e refund. |
| **Campaigns** | Campanhas por tenant; criação/edição por dono. |
| **Contents** | Conteúdos associados a campanhas. |
| **Tokens** | Tokens de utilidade (aquisição por campanha). |
| **Xion / Blockchain** | Deploy de factory CW20, criação de token por tenant, registro de compras, mint de NFT. |
| **Transactions** | Registro e listagem de transações. |
| **Credits** | Sistema de créditos: saldo, histórico, concessão e reembolso. |
| **Marketplace** | Marketplace P2P para venda e compra de chaves entre usuários. |
| **Splits** | Distribuição de receita entre artistas e plataforma. |
