**Serviço de autenticação e autorização do MKClub.**

## Visão geral

Este serviço é responsável por:
- **Login** (email/senha) e **registro** de usuários
- Emissão de **JWT** (access + refresh token)
- **Perfil** do usuário autenticado (inclui `access_role` e `tenant_id` para multi-tenant)
- **Reset de senha** (solicitação por email + conclusão com token)
- **Google OAuth** para login social

## Fluxo típico

1. `POST /auth/login` com `email` e `password` → retorna `accessToken` e `refreshToken`
2. Enviar `Authorization: Bearer `accessToken`` nas requisições ao Admin Backend e neste serviço
3. Quando o access token expirar, usar `POST /auth/refresh` com o `refreshToken` para obter novos tokens

## Roles (access_role)

| Role | Descrição |
|------|-----------|
| **SuperAdmin** | Acesso total ao admin; `tenant_id` nulo |
| **Admin** | B2B; cria e gerencia seus próprios tenants |
| **TenantAdmin** | Admin de um tenant específico; `tenant_id` preenchido |
| **User** | Usuário final |
| **Star** | Artista/estrela vinculado a campanhas |
